Place local proprietary runtime files here only for your own working copy if needed.

This directory is intentionally excluded from Git except for this README and .gitignore.

Supported local inputs through the application:
- a user-provided DLSS / Streamline ZIP
- a user-provided nvngx_dlssnr.dll

The manager validates the known package fingerprints and stages selected files into the chosen Minecraft instance. Nothing in this folder is required for normal source builds.
