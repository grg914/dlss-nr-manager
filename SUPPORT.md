# Support

## Bugs

Use a GitHub issue for reproducible application bugs.

Useful information:

- DLSS NR Manager version/commit;
- Windows version;
- GPU model/driver;
- affected feature;
- exact error text;
- reproduction steps;
- whether the affected component is installed from the manager-owned Downloads channel.

Attach logs only after reviewing them for sensitive information.

## Security

For vulnerabilities, do **not** post exploit details, secrets or sensitive payloads in a normal public issue.

Follow [SECURITY.md](SECURITY.md).

## Licensing / redistribution

For questions about whether a runtime/model/source can be mirrored into DLSS NR Manager Releases, reference:

- [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)
- [Component lifecycle policy](docs/COMPONENT_LIFECYCLE_POLICY.md)
- the exact upstream license

A public download URL is not sufficient proof of redistribution rights.

## Large model/runtime issues

For download/install problems include:

- component/model id;
- package/release tag;
- expected total size;
- failed chunk/asset name if shown;
- SHA/integrity error text;
- whether retry/remove/redownload was attempted.

Do not attach restricted model weights or licensed SDK binaries to issues.
